A desktop that fits your day

Everything in its own place.

Personal and Work start with nine workspaces each, arranged as two logical 3 × 3 grids. The label in GNOME’s top panel keeps your current environment and workspace in view.

For example, Personal: 2 / 9 means you’re in the Personal environment, on workspace 2 out of its 9 workspaces. The label updates as you switch, and uses your custom environment names. Click it to switch environments or move the focused window to the other environment.

Start with a little separation.

Version 0.2.0 targets GNOME Shell 46. Choose the installation method that suits you.

1. GNOME Extensions website

The easiest method. Visit the extension’s page on extensions.gnome.org.

Visit GNOME Extensions ↗

2. Download the release ZIP

No cloning, Node.js, or build tools needed. Download the latest installable extension ZIP directly. This link automatically follows new GitHub releases.

Download from GitHub ↗

On GNOME Shell 46, disable an existing installation first. Then download and install the latest release as your normal user: 

zip=$(mktemp --suffix=.shell-extension.zip) &&
wget -O "$zip" \
  https://github.com/ihoru/gnome-environments-switcher/releases/latest/download/environments-switcher@ihoru.github.io.shell-extension.zip &&
gnome-extensions install --force "$zip" &&
rm -f "$zip"

Log out and back in, then enable Environments Switcher in the Extensions app. The full guide below covers upgrades and the old prototype.

3. Build from source

Use Node.js 24 for development checks. The extension itself runs with GNOME Shell and GJS. 

sudo apt install gnome-shell gnome-shell-extension-prefs libglib2.0-bin python3
git clone https://github.com/ihoru/gnome-environments-switcher.git
cd gnome-environments-switcher
npm ci
npm run check

Install and enable

Disable any existing installation first. Then install the checked bundle as your normal user: 

gnome-extensions install --force dist/environments-switcher@ihoru.github.io.shell-extension.zip

Log out and back in, then enable it in the Extensions app or run:

gnome-extensions enable environments-switcher@ihoru.github.io

Before you install

A workspace organizer.
Still your GNOME desktop.

Environments do not isolate applications, files, notifications, accounts, or data. They do not relaunch your applications after logout.

The extension temporarily adjusts workspace settings and claimed native shortcuts, restoring them on disable when you have not changed them since. Sticky windows stay visible across workspaces and are not moved by the extension.

Other GNOME versions are not declared supported. Avoid overlapping workspace and animation extensions. Final X11, Wayland, and multi-monitor live checks remain pending.

Workspace counts are advanced settings, not controls on the preferences page. Nine per environment is the tested design target.
